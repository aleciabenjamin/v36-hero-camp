**Hur fungerar CSS-arv? — och ge ett konkret exempel från din egen Hero-kod**
CSS-arv innebär att ett underliggande element (barn-element) automatiskt ärver vissa stilar från sitt överliggande element (förälder-element).
Vi sätter color och font-family på hero-klassen, då får h1, .datum, .plats och .tagline alla samma färg och typografi eftersom de är barn till .heros förälder.
